# 单文件奖学金答辩演示

11 页 HTML 幻灯片。样式、脚本与图片全部内联在一个文件里，双击 `index.html` 即可放映，不联网，没有外部依赖，也不需要构建步骤。

数据与素材均已脱敏：姓名、学号、班级、绩点、导师姓名全部替换，书院与奖项名称改为"某书院 · 奖学金答辩"，人物照片、奖状、成绩单、书信照片与散文内页统一做了马赛克处理，校徽与院徽换成占位图，页面文案也换成演示用的占位内容。

## 操作

| 键 | 作用 |
|---|---|
| → / 空格 / 点击右半屏 | 下一页 |
| ← / 点击左半屏 | 上一页 |
| F | 全屏 |
| Home / End | 首页 / 末页 |

## 页面与动效

1. 封面：三色标题与竖版照片
2. 结构：Canvas 双椭圆轨道与 444 条 SVG 描边逐笔画出
3. 学习：数字滚动、成绩卡放大镜、公式沿曲线循环上飘
4. 科研：四步流程逐级入场，论文图与两张实验照斜叠
5. 竞赛：奖状放大镜、照片轮播
6. 实践：分段行程线自画出，纸飞机随后出现并缓慢摆动
7. 体育：2×2 模块、页脚 15 项运动图标横向滚动、书法图呼吸光晕
8. 文艺：3D 翻页书，14 张叶片按深度排序逐张翻过
9. 创业：五步流程图逐个浮现，产品窗口四帧轮播
10. 社工与志愿：向右上收束的照片长廊，大图遮小图
11. 收尾：标题回扣

## 实现要点

- 舞台固定 1280×720，按窗口等比缩放并居中，翻页用 3D 变换配合 `perspective`
- 页内动效全部是 CSS 动画，进场延迟由自定义属性 `--d` 逐条错开，翻页时重新触发
- 背景粒子、结构页轨道与实践页曲面是 Canvas 2D 手写投影，未使用任何第三方库
- 图片以 base64 内联，单文件约 1.72MB
